# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | yes       |
| < 0.1   | no        |

## Reporting a Vulnerability

If you discover a security vulnerability, please email fatih.hekim1@hotmail.com with the subject prefix `[markowitz-optimizer security]`. Please do not open a public issue.

You will receive an acknowledgement within 7 days. If the vulnerability is confirmed, a patch will be released in the next minor version. Critical vulnerabilities will be patched immediately and disclosed in the changelog.
